Baixar para Windows

Baixe o allmusic.exe e abra. Não há nada para instalar antes, e o app não pede senha de administrador.

Primeira vez que você abrir

O arquivo ainda não tem assinatura digital, então o Windows mostra um aviso na primeira execução. É esperado:

  1. Abra o allmusic.exe.
  2. Se aparecer a tela azul “O Windows protegeu o computador”, clique em Mais informações.
  3. Clique em Executar assim mesmo.

O aviso aparece porque o Windows não conhece o editor do programa, não porque encontrou algo no arquivo. Se preferir não confiar no arquivo pronto, confira a assinatura abaixo ou compile a partir do código.

Conferir o arquivo

O SHA-256 abaixo é o do arquivo publicado. Se o do seu download for igual, ele não foi alterado no caminho.

Veja o valor na página da versão no GitHub.

Para calcular o do arquivo que você baixou, abra o PowerShell na pasta de downloads e rode:

Get-FileHash allmusic.exe -Algorithm SHA256

Remover o app

Não há desinstalador porque nada é instalado. Feche o ALL MUSIC pelo ícone da bandeja, apague o allmusic.exe e, se quiser remover também seus dados locais, apague a pasta %LOCALAPPDATA%\allmusic.

ALL MUSIC é um projeto independente de código aberto. Não é afiliado, patrocinado nem endossado pelo Spotify ou pelo YouTube. A reprodução do Spotify exige conta Premium.
